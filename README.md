# Karigar Connect 🏺

### **AI-Driven E-Commerce & Business Lifecycle Platform for Marginalized Artisans**
**SIH 2026 Problem Statement:** SIH26090  
**Ministry:** Ministry of Social Justice and Empowerment (MoSJE)  

---

## 📖 Project Overview
**Karigar Connect** is an intuitive, AI-driven virtual business manager application designed to bridge the gap between traditional Indian craftsmanship and modern digital commerce. Built specifically for low-literacy artisans, weavers, and micro-entrepreneurs, the platform automates cataloging, product photography enhancement, pricing, and logistics to secure year-round financial independence.

---

## ✨ Key Features & Innovations

1. **Voice-First Vernacular Cataloging Engine (Core)**: Allows artisans to describe products in native dialects (e.g. Hindi, Tamil). The AI structures professional English titles, descriptions, categories, and HSN codes automatically.
2. **AI Image Enhancer & Studio (Core)**: Automatically removes cluttered workspace backgrounds and overlays products onto premium, professional studio backdrops.
3. **Dynamic Pricing Assistant (Core)**: Computes fair retail and wholesale suggestions based on raw material costs, labor hours, and state-mandated minimum daily wages.
4. **ONDC API Gateway**: Publishes products directly onto the open national ONDC network to unlock zero-commission sales on apps like Paytm, PhonePe, and Mystore.
5. **Vikas Khata Ledger with local-language audio readouts**: An offline bookkeeping tool that reads out balances and receipts in regional languages to assist semi-literate users.
6. **Collaborative Postal Pooling**: Aggregates packages in the same village cluster to secure bulk shipping discounts from India Post.
7. **Offline-First Storage**: Caches transactions locally and automatically synchronizes to cloud databases when internet connection is restored.

## 🛠️ Tech Stack
* **Frontend**: Responsive Mobile/Web Single Page Application (HTML5, Tailwind CSS, JavaScript)
* **Backend**: Python (FastAPI / SQLAlchemy)
* **Database**: PostgreSQL (Production) / SQLite (Local development & on-device)
* **AI/ML integration**: Google Generative AI (Gemini SDK) + OpenAI Whisper API
